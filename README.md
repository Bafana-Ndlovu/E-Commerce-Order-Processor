# E-Commerce Order Processor

## Project Description
A front-end JavaScript application that processes, cleans, analyses, and reports on e-commerce orders. Built step by step through 10 challenges.

## Technologies
- HTML
- Tailwind CSS
- JavaScript

## Built-In Objects Used
| Feature | Built-In |
|---------|----------|
| Clean customer data | String |
| Calculate prices | Number, Math |
| Work with dates | Date |
| Search/filter | Array methods |
| Unique categories | Set |
| Product lookup | Map |
| Export/import | JSON |
| Validation | RegExp |
| Statistics dashboard | All of the above |

## How to Run
1. Clone the repository.
2. Open `index.html` in a browser.
3. All functionality is visible and testable in the browser — no backend required.

## Interface Review

Tailwind only: Ensure all sections (Orders, Search/Filter, Statistics, Categories, Product Lookup, Data Processing) are styled with Tailwind classes — no custom CSS.

Consistency: Use consistent spacing (p-4, mb-2), rounded corners (rounded), and shadows (shadow-md) for all sections.

Usability: Inputs and buttons should be clearly labeled, with hover states (hover:bg-blue-600) for better UX.

Organization: Each section should have a heading (text-xl font-semibold) and content grouped logically.
